01 · 什麼是 LLM

LLM：大型語言模型

大

Large

參數多、讀過的文字多，抓得住語言細節。

語

Language

處理文字與符號：中文、英文、程式碼都算。

模

Model

從大量資料學到語言規律的數學系統。

一台超強的文字預測引擎。
01 · 什麼是 LLM

本質是一場超強的「文字接龍」

看前面的字，猜下一個字最可能是什麼：

「今天天氣真＿＿」

好 82%熱 11%糟 5%

🧩 Token

模型把文字切成詞塊來讀：今天＋天氣＋真＋的＋很＋好。用量、費用都以 Token 計算。

📏 Context Window

一次能記住的長度有上限。對話太長時，最早交代的規則可能被「忘記」，適時開新對話。

01 · 什麼是 LLM

會生成，不會查證

LLM 不是在查資料庫，而是把規律「壓縮」進模型。沒把握時，它會一本正經地說錯，這叫幻覺。

對策：把 LLM 當成「很會講的實習生」。好用，但重要的事要複查，也要它附上出處。
很會講，但關在罐子裡。

02 · 從 LLM 到 AI Agent

Agent 怎麼工作？想 ➔ 做 ➔ 看 ➔ 修

💭

想

拆解任務，決定用哪個工具

➔
🛠️

做

呼叫工具：開網頁、寫檔、跑指令

➔
👀

看

讀取結果，判斷成功或失敗

➔
🔁

修

出錯就換方法；成功就下一步

Agent ＝ 大腦（LLM）＋ 手腳（工具）＋ 不斷修正的循環。
講師示範 · 人間 Agent

Agent 沒有魔法

🗣️ 使用者：幫我看看吉他社這星期有什麼活動？要花多少錢？
🤖 Agent：我沒有社團資料的讀取權限。請提供「社團活動資料卡」並授權我讀取。
🗣️ 使用者：好，授權你讀取這張資料卡，摘要給我。
🤖 Agent：讀取完成：成發活動在本週五 19:00，城中 5117，資料卡寫「免費入場」。
Agent 要靠明確的授權、可靠的資料來源和可用的工具，才能完成任務。

03 · 什麼是 Agentic AI

越自主，越要有人把關

🔍

研究員 Agent

上網檢索、抓資料

✍️

寫手 Agent

把資料寫成草稿

🧐

檢查員 Agent

校對格式、抓錯

人在迴圈（Human-in-the-loop）：刪檔、付費、寄信、處理個資等不可逆動作，一律「先問你，批准後才執行」。

04 · 教室守則

4 大教室守則

🔑 金鑰不外流

API 金鑰、Token 就像密碼，不貼給別人、不上傳公開網路。今天你會第一次拿到自己的 Gemini API 金鑰。

🔍 重要的事再確認

AI 會一本正經說錯，產出一定要自己複查。

⚠️ 不亂刪、不亂送、不亂裝

刪檔與寄信先想清楚；只安裝講師審核過的 Skill。

🔒 尊重隱私

不讓 AI 讀取或外洩他人的私人資料與未公開校務訊息。
