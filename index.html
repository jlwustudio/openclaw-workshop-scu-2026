Topic ideas

選題靈感：從身邊的校園問題開始

以下只是發想方向，不是必選題；也可以帶自己的問題想法。選定後，透過 OpenClaw 打造一個小而可驗證的 AI 助理，並做「使用者測試與回饋修正」。

🌿 永續校園

環境、能源、減塑或資源循環議題（如：空調節能提醒、二手書循環配對）。

🚀 新服務點子

發掘同學的潛在需求，做出服務原型（如：跨系專長媒合、履歷自傳修改教練）。

⚡ 流程改善

鎖定校園中費時的流程，做資訊整理與草稿助理（如：跨校區選課提醒、社團場地借用檢核表）。

🧭 校園資源導讀

把分散的校內資源整理成好找的入口，只做資源指引、不代做決定（如：校內協助資源導讀、國際生校園生活導覽）。

A working habit

好的 AI 協作，從一個清楚的需求開始。

不需要背複雜咒語。先把你真正要解決的問題、已知的資訊與期待的結果說明白，再讓 AI 協助你拆解與執行。

我想做什麼？描述具體任務與對象。
我已經知道什麼？提供資料、限制與背景。
我如何判斷完成？定義格式、檢查方式與下一步。
Before we meet

課前先準備好這幾件事

01

帶自己的筆電

請攜帶 Mac 或 Windows 筆電與電源線；需能安裝 Node.js：Mac 第一次裝 Homebrew、Windows 安裝 Node.js 都會要求輸入電腦密碼或允許變更（學校或公司管理的電腦可能被鎖）。

02

課前在家：下載與安裝

請在上課前到 https://github.com/jlwustudio/openclaw-workshop-scu-2026，按綠色「Code」➔「Download ZIP」下載整份教材，依 Day 1 S01 安裝 Node.js 與 OpenClaw，並用個人 Gmail 完成 Google AI Studio 的專案與 API 金鑰（安裝手冊 Part A）；Mac 請用 Homebrew 安裝 Node.js。教室 Wi-Fi 多人同時下載會很慢，Day 1 第一節只用來檢查與補救。在家測試只要確認助理有回應即可，不用多聊：前一天下午 4 點之後的用量會算進上課當天的額度。

03

帳號與問題想法

請準備個人 Gmail 與 AI Studio 金鑰（學校帳號可能無法建立專案）、登入 Telegram，並攜帶可接收驗證碼的手機；帶一個你想解決的校園問題。頁面頂端燈號可檢測 OpenClaw Gateway 是否連線。

系統需求

  • 作業系統：macOS 13+（Apple Silicon 或 Intel）或 Windows 10 22H2 / Windows 11（64-bit）。
  • 記憶體：建議 8GB RAM 以上。
  • 權限：安裝 Homebrew 或 Node.js 時會要求輸入電腦密碼或允許變更；裝好後日常操作用一般使用者帳號即可。不要隨意在指令前加 sudo。
