# 練習資料

本資料夾所有內容皆為虛構資料，只供「打造你的第一個 AI 助理」工作坊練習使用。

## 使用方式

1. 將整個 `sample-data` 資料夾複製到 OpenClaw 的 workspace。
2. 練習檔案整理時，請先把 `待整理` 複製一份並改名為 `練習`。
3. 只在 `練習` 資料夾中進行移動、改名或刪除；原始資料請保留。

## 內容

- `學生社團調查.csv`：虛構的社團活動偏好調查，可用於 CSV 分析。
- `待整理/`：幾份故意命名混亂的文字檔，用於分類、重新命名與版本判讀。
- `網頁練習網址.txt`：可用於網頁擷取與摘要練習的公開網站。
- `校園活動摘要需求.md`：Day 2 上午網頁擷取練習的需求與輸出條件。
- `校園 FAQ.md`：可用於 Skills 設計練習的虛構問答資料。

## Day 2 Skill 與安全驗收

請依 [課堂唯讀設定](../workshop-config/README.md) 建立獨立工作區，只複製 FAQ 與選題靈感案例庫，並照 [本機最小 Skill 範本](本機最小Skill範本.md) 自己建立 `SKILL.md`，不要把整份練習資料當作單一檔案的權限限制。
